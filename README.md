# Survey Clustering Studio

An interactive machine learning web app built with Streamlit for analyzing survey and mixed-type datasets using clustering.

The app helps users upload survey/company datasets, preprocess responses, reduce dimensionality using FAMD, generate clusters, and visualize hidden respondent segments.

---

## Live App


[Launch SME Clustering App](https://sme-clustering.streamlit.app/)

---

## Features

- Upload CSV datasets
- Automatic preprocessing
- Handles numerical + categorical data
- FAMD dimensionality reduction
- KMeans clustering
- Auto-select or manual cluster count
- Cluster summaries
- Interactive charts
- Download clustered results
- Optional model saving
